# 공통 디자인 엔진 0.4.0

기존 공개 화면의 데이터·계산·SVG 렌더러를 유지하며 공통 중립색·청록색, 카드 여백, 표 정렬·가독성, 44px 조작 영역을 연결한다. 보조 차트·측정·CSV 도구는 접고 검색 해제는 검색 중에만 표시한다. 키보드 포커스와 원래 이벤트를 보존한다.

로컬 미리보기의 검증된 presentation-040.js와 engine-040.css를 공식 빌드 소스에 이식했다. localhost 라우팅 및 캡처 데이터는 포함하지 않는다. 기능 검증: 차트 키보드/범례/구간 선택, 실제 표 정렬과 검색·CSV 일치, 390px와1440px 레이아웃.
