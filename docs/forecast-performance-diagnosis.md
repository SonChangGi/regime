# 국면 예측 성능 진단

2026년 9월 4일 데이터가 반영된 동결 예측을 독립 재계산했다. 현재 공식 모델은 **전환 40회 중 3회를 제때 포착했고, 악화 전환은 19회 중 0회**다. 숫자 표기의 오류가 아니라 예측 목적과 실제 성능에 개선이 필요한 상태다.

## 무엇을 포착했는가

`전환 포착`은 다음 주의 최빈 예측 국면이 현재 국면과 달라지고, 실제로도 국면이 바뀐 경우다. 다음 주 국면을 확률 합계가 가장 큰 상태로 고르는 `argmax` 기준이며, 별도 저임계값 경보와 다르다. 정확한 도착 국면까지 맞췄는지도 별도로 계산했다.

| 실제 변화 | 전환 수 | 제때 이탈 포착 | 도착 국면도 정답 |
|---|---:|---:|---:|
| 위험선호 → 중립 | 15 | 0 | 0 |
| 중립 → 위험회피 | 4 | 0 | 0 |
| 위험회피 → 중립 | 5 | 1 | 1 |
| 중립 → 위험선호 | 16 | 2 | 2 |
| 전체 | **40** | **3** | **3** |

포착한 3회는 모두 회복 방향이다. `악화`는 위험선호에서 중립·위험회피로, 또는 중립에서 위험회피로 이동하는 것으로 고정했다. `중립 상태 맞히기`와 이 사건은 다른 목표다.

40회 중 33회는 다음 전환 전까지 새 국면을 한 번 이상 예측했지만, 인식 지연 평균은 0.91주다. 전환 이후 국면을 인식하는 능력을 사전 포착률로 대체할 수 없다.

## 기존 모델과 동일 조건 비교

모든 모델은 동일한 191개 원점과 동일한 다음 주 실제 국면으로 평가했다. 자료의 마지막 관측일은 2026-09-04이며, 결과가 확인된 마지막 예측 원점은 2026-08-28이다.

| 모델 | Log loss ↓ | Brier ↓ | 이탈 포착 | 오경보 | 이탈 AP ↑ | 악화 포착 |
|---|---:|---:|---:|---:|---:|---:|
| 공식 동적 앙상블 | 0.494972 | 0.300560 | 3/40 | 2 | 0.447761 | 0/19 |
| XGBoost | 0.493123 | 0.295019 | 6/40 | 3 | 0.458994 | 0/19 |
| 최근 208주 가중 XGBoost | 0.486490 | 0.286940 | 8/40 | 5 | 0.479915 | 0/19 |

`AP`는 비보간 Average Precision이며 사다리꼴 적분 PR AUC와 구분한다. 이탈 사건 비율은 20.94%다. 기존 XGBoost 계열에 순위 개선의 여지는 있지만, 가장 좋아 보이는 기존 모델로 바꾸기만 해도 악화 포착 문제가 해결되지는 않는다.

최근 2025~2026년 87주를 따로 보면 공식 모델은 Log loss 0.577696, 이탈 1/21, 악화 0/10이다. 최근 가중 XGBoost는 0.536849, 이탈 3/21, 악화 0/10이다.

## 낮은 성능의 구체적인 원인

**전체 확률 오차가 국면 유지 구간에 지배된다.** 공식 모델은 선택 기간 2016~2022년에도 이탈 36회 중 0회만 최빈 국면으로 예측했다. 당시 365주 중 이탈은 9.86%였다. 이탈 시 손실이 커도 대다수 유지 주간에서 확률을 잘 맞히면 전체 Log loss가 좋아진다. 2023년 이후에도 유지 151주의 평균 Log loss는 0.166519, 전환 40주는 1.734883이다.

**최근 전환 빈도가 올라갔다.** 2023년 9/52회, 2024년 10/52회, 2025년 7/52회에서 2026년은 14/35회다. 2026년 실제 이탈률 40%에 비해 평균 예측 이탈확률은 19.14%이고, 제때 포착은 0회다. 새 국면이 1~2주 만에 끝나는 전환도 선택 기간 6/36회에서 진단 기간 17/40회로 늘었다. 이 수치는 사후 길이 분석이며 예측 입력에 사용하지 않는다.

**악화와 회복의 예측 강도가 다르다.** 실제 악화 주의 평균 이탈확률은 16.7~17.8%, 회복 주는 32.3~32.8%다. 현재 국면을 떠날 가능성과 떠난 뒤의 방향을 별도로 점검해야 한다.

**국면 경계의 거리는 쓸 만한 정보다.** 당시까지 알려진 국면 점수에서 실제 이탈 경계까지의 거리를 국면 임계값 폭으로 나누어 확인했다.

| 원점의 경계 거리 | 2016~2022 실제 이탈률 | 2023~2026 실제 이탈률 |
|---|---:|---:|
| 0.125 이하 | 10/30 · 33.3% | 11/21 · 52.4% |
| 0.125~0.25 | 13/53 · 24.5% | 16/51 · 31.4% |
| 0.25~0.5 | 9/118 · 7.6% | 12/75 · 16.0% |
| 0.5~1 | 4/94 · 4.3% | 1/31 · 3.2% |
| 1 초과 | 0/70 · 0% | 0/13 · 0% |

방향별 경계 거리, 점수 변화, 국면 지속기간, 다음 관측에서 기존 창의 오래된 값이 빠지는 효과를 반영한 예측이 우선 후보가 된다. 이 관계는 과거 선택 기간에도 존재하므로 최신 결과에만 맞춘 근거가 아니다.

## 임계값만 낮추면 해결되는가

공식 모델에서 2016~2022년의 연간 오경보 2회 기준으로 정한 이탈확률 임계값 0.257464를 이후에 그대로 적용하면 **15/40회**를 포착한다. 그러나 오경보가 **19회, 연 5.19회**가 되어 선택 시점의 목표를 크게 넘긴다. 악화 경보도 5/19회로 늘지만 오경보 연 4.64회다.

같은 2023~2026년 구간에서 실현 오경보를 7회, 연 1.91회로 맞춘 **사후 순위 비교**에서는 공식 모델 7/40, 최근 가중 XGBoost 13/40이다. 악화는 각각 2/19, 4/19다. 이 비교는 낮은 오경보 영역의 순위 정보 진단이며, 이 기간의 정답으로 운영 임계값을 선택하는 근거로 쓰지 않는다.

기존 별도 `binary_xgboost` 이탈 경보는 임계값 0.1에서 35/40회를 포착하지만 오경보가 88회, 연 24.04회다. 서로 다른 경보 빈도의 포착률만 비교해 모델 개선으로 표시하면 안 된다.

## 개선 후보의 평가 기준

1. **정답과 원점을 고정한다.** 기존 국면 정의와 일주일 예측 시점을 유지한다. 더 쉬운 새 라벨이나 4주 이내 경보를 일주일 국면 예측의 개선으로 합치지 않는다. 전환 전체·악화·회복·정확한 도착 국면을 함께 남긴다.
2. **선택과 진단을 분리한다.** 현재 동결 OOS는 2016년부터다. 2015년 검증 자료가 있다고 표시하지 않는다. 모델 구조와 임계값은 2022년까지의 시간순 검증으로 선택하고, 각 원점에서는 그때 결과가 완성된 행만 사용한다. 2023년 이후는 이미 본 진단 기간이며, 2025년 이후를 별도 최근 감사로 병기한다. 이 구간의 결과를 보고 후보를 바꾸면 그 사실도 남긴다.
3. **확률과 경보를 모두 개선한다.** 같은 원점의 multiclass Log loss·Brier, 이탈·악화 AP, 경보 횟수·적중률·재현율을 함께 비교한다. 악화 AP에는 이미 위험회피여서 더 악화할 수 없는 원점을 제외한 분모와 사건율도 제공한다. Log loss만 낮추거나 경보만 늘린 후보를 종합 개선으로 승격하지 않는다.
4. **오경보 예산을 먼저 정한다.** 연 2회 같은 주 기준과 연 4·8회 민감도를 후보 결과 확인 전에 고정한다. 실제 과거 정보로 결정한 경보 정책의 이후 포착률·실현 오경보를 우선 평가하고, 같은 실현 오경보에서의 사후 PR 비교는 별도 표로 둔다. 경계 확률 동률도 전부 포함해 예산 초과를 숨기지 않는다.
5. **연도별·최근 성능과 불확실성을 확인한다.** 같은 원점의 후보−기존 모델 차이를 주 단위 블록으로 재표집하고 전환 수·악화 수를 함께 기록한다. 특정 위기 한 번의 이득이나 최근 과대 경보가 전체 평균에 가려지는지 확인한다. 승격은 이 진단과 시간순 선택 조건을 통과한 후보에만 적용한다.

## 재현과 근거

```bash
PYTHONPATH=src /Users/changgison/projects/regime/.venv/bin/python \
  scripts/diagnose_forecast_transitions.py \
  --source /Users/changgison/projects/regime-improvements/build/release-20260904 \
  --output build/forecast-performance/diagnosis
```

`diagnosis.json`에는 입력·산출물 SHA256과 공식 지표 대조 결과가 있다. 11개 모델의 6,116개 예측을 국면 원자료와 원점별로 대조했으며, 기존 `evaluate_predictions`와 저장된 leaderboard의 핵심 8개 지표가 일치했다. 입력 파일의 실행 전후 해시는 동일하다. 데이터 수집·재학습·발행은 수행하지 않는다.

- `forecast-rows.csv`: 모든 예측, 실제 사건, 세 방향 확률, 경계 거리, 손실.
- `period-summary.csv`, `yearly-summary.csv`, `transition-types.csv`: 동일 조건의 모델·시기·방향 비교.
- `probability-bins.csv`, `boundary-distance-bins.csv`, `duration-bins.csv`, `target-episode-bins.csv`: 확률·경계·기간 진단.
- `false-alarm-budgets.csv`: 과거 선택 임계값의 이후 성능과 사후 순위 비교를 분리한 결과.
- `hazard-summary.csv`: 기존 별도 이탈 경보의 확률 정확도와 실제 경보 횟수.
