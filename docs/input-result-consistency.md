# 입력과 결과의 적용 범위

모델 비교 지표를 선택한 관측 주와 예측 분석 기간에 맞춰 다시 계산한다. 확률 차이가 작아 같은 값처럼 보이던 모델은 Log loss 소수점 네 자리와 운영 모델 대비 차이, 예측 국면 일치 횟수로 구분한다. 같은 국면을 예측했다면 포착·오경보 횟수는 실제로 같을 수 있다.

| 화면 | 적용 입력 | 결과와 기간 |
|---|---|---|
| 예측 분석·모델 비교 | 관측 주, 비교 모델, 예측 분석 기간 / 평가 기간 | 해당 주 예측확률, 이력, 완료 예측의 지표·순위·모델 간 차이. 두 기간 선택기는 같은 값을 공유한다. |
| 자산 성과 | 실제/예측 국면, 평균 기준, 보유 기간, 상세 자산. 예측 국면에서는 비교 모델도 적용 | 전체 검증 기간의 자산 통계. 평균 기준은 평균·신뢰구간·초과수익·벤치마크를 함께 바꾸며, 상세 자산은 아래 상세표에 적용한다. |
| 전략 성과 | 비교할 전략 | 공식 정책과 비교 전략의 전체 검증 기간 성과. 전략 선택은 차트와 비교표의 표시 대상을 바꾼다. |
| 조기 경보 | 위험 악화 / 모든 국면 이탈, 선정 구간의 연간 오경보 한도 | 전환 모델·시장 경보 기준의 전체 검증 기간 진단. 선택한 한도로 과거 선정 구간에서 정한 임계값의 이후 성과를 보여준다. |
| 보유 비중 계산 | 현재 비중, 평가금액, 정책 목표 / 이번 실행 목표 | 최신 공식 실행정책의 목표 대비 조정량. 첫 계산 이후 입력을 바꾸면 즉시 갱신한다. |

예측 분석의 기간은 예측을 만든 관측 주를 기준으로 자른다. 그중 선택일에 결과가 확정됐고 모든 비교 모델에 같은 대상 주의 예측이 있는 공통 표본으로 평가한다. 아직 결과가 없는 마지막 예측은 확률을 표시하되 평가에서 제외하며, 관측 주 수와 완료 평가 수를 구분해 보여준다. 전체 기간을 선택해도 선택한 관측 주 이후 결과는 모델 평가에 포함하지 않는다.

Log loss와 Brier는 예측확률의 오차이며 낮을수록 좋다. 국면 변화 포착은 실제 다음 주 국면이 현재와 달라진 사건 중 모델도 변화를 예고한 횟수다. 위험 악화와 회복을 함께 세므로 방향별 포착 횟수를 함께 표시한다. 운영 대비 확률 차이는 공통 표본의 세 국면 확률에 대한 평균 절대 차이이며, `%p`로 표시한다. 이 값과 선택 기간 순위는 기존 과거 재구성 예측을 다시 집계한 결과다. 실제 발행 후 성과는 운영 기록에서 따로 확인한다.

보유 비중 계산기는 최신 관측 주와 공식 신호의 기준일이 일치할 때 표시한다. 과거 날짜에서는 숨기고, 최신으로 돌아오면 입력을 유지해 다시 계산한다. 잘못된 입력은 이전 조정량 대신 오류를 표시한다. 비교 모델 선택은 이 계산기의 공식 목표를 바꾸지 않는다.

현재 화면 링크에는 관측 주·모델·기간·자산 조건과 경보·전략 선택을 저장한다. 보유 비중과 평가금액은 링크에 넣지 않는다. 이전 이력이 아직 로드되지 않은 상태에서 과거 날짜나 긴 기간을 선택하면 필요한 이력을 불러온 뒤 선택을 적용한다.

변경 범위는 웹의 입력 상태, 파생 평가, 표시와 회귀 테스트다. 기존 데이터와 API를 다시 수집하거나 감사하지 않으며, 모델 재학습과 공식 모델 선정·실행정책 변경도 포함하지 않는다.

## 검증

2026-09-04 공개 원본으로 13개 모델의 전체·최근 52주·과거 시점 지표를 Python `evaluate_predictions`와 대조했다. 최신 52개 관측 주에는 완료 예측 51개와 결과 대기 1개가 있으며, 동적 앙상블 Log loss는 0.6345, 멀티스케일은 0.6349다. 두 모델의 예상 국면은 이 구간 모두 같아 포착 횟수도 0/14회로 같다. 전체 기간은 각각 0.4950·0.4953과 3/40회이며, 멀티스케일의 2025-12-26 기준 52주 결과는 0.4071과 1/7회다.

실제 브라우저에서 모델·두 기간 선택기·과거 날짜를 바꿔 요약, 차트, 순위표의 동시 갱신을 확인했다. 자산 기준·기간·평균·상세 자산, 전략 표시, 보유 금액 변경도 결과에 반영된다. 390px 화면에서 가로 넘침 없이 모델과 평가 기간을 선택할 수 있다. 관련 로컬 검사 215개 및 공개 패키지 검증이 통과했다. 회귀검사에는 0개 완료 표본, 미래 결과 제외, 누락된 공통 표본, 지연 이력 로딩 중 마지막 날짜 선택 보존, 링크 복원이 포함된다.
