# 국면 예측 모델 독립 검증

`boundary_filtered_history`는 기존과 동일한 2023년 이후 **191주**에서 확률 예측과 전환 포착을 개선했다. 현재 동결 입력에서 미래 정보 유입이나 공식 라벨 계산 불일치는 발견되지 않았다. 다만 기본 예측의 개선은 회복 전환에서 나왔으며, 악화 전환은 여전히 별도 개선이 필요하다.

## 동일한 예측 시점에서 확인한 결과

후보 선택은 공통 2016~2022년 선정기간의 국면 Log loss로 수행했다. 아래 진단 점수는 후보 선택에 사용하지 않았다.

| 지표 | 운영 동적 앙상블 | 최근 가중 XGBoost | 경계·과거수익률 모델 |
|---|---:|---:|---:|
| 국면 Log loss | 0.494972 | 0.486490 | **0.365558** |
| 국면 Brier | 0.300560 | 0.286940 | **0.223439** |
| 전환 Log loss | 0.460529 | 0.455156 | **0.357142** |
| 전환 Brier | 0.148409 | 0.142459 | **0.111159** |
| 전환 AP | 0.447761 | 0.479915 | **0.657521** |
| 기본 예측의 전환 포착 | 3/40 | 8/40 | **16/40** |
| 기본 예측의 오경보 | 2회 | 5회 | 3회 |

기본 예측은 다음 주 확률이 가장 높은 국면(argmax)이 현재 국면과 다른 경우를 뜻한다. `P(이탈) ≥ 50%`와 같은 정책으로 섞지 않았다. 운영 모델보다 오경보가 1회 많으므로 16/40을 “동일 오경보 포착률”이라고 부르지 않는다. 확률 점수의 개선은 경보 임계값 변경 없이 확인됐다.

초기 `boundary/full`은 2022-12-30→2023-01-06 한 주를 추가로 포함해 진단 표본이 192주였다. 기존 공식 OOS는 선정·진단 경계를 넘는 이 origin을 제외한다. 감사 대상인 `boundary/aligned`는 이 origin을 학습 완료 OOS 교정 이력에서도 제외하고 다시 실행했다. 최종 후보 5개와 기준선 모두 선정 365주·진단 191주로 일치한다.

## 실제 입력으로 검증한 항목

| 검증 | 결과 |
|---|---|
| 공식 라벨 재구성 | 1,079주 전체 상태 일치. 최초 520주(2006-01-06~2015-12-18)에만 라벨 파라미터 적합 |
| 실제 수익률을 넣은 다음 주 점수 | 가능한 OOS 557주 모두 공식 계산과 일치. 최대 절대 오차 `1.12e-13` |
| 실제 다음 주 상태 | 557주 모두 공식 hysteresis 상태 전이와 일치 |
| 가상 수익률 | 실제 과거 20개 시점 × -30%~+30% 로그수익률 9개 조건. 공식 재계산과 최대 오차 `4.33e-14` |
| 경계 부등호 | 3개 시작 상태에서 54개 경계·인접값을 공식 `transform`과 대조해 일치 |
| 미래 시계열 변조 | 2020-01-03·2025-03-07 이후 모든 수치열을 변경해도 이전 피처·기계 확률·최종 교정 확률이 비트 단위로 동일 |
| 분류기 미래 정보 차단 | 같은 두 변조에서 각 시점 직전 3개 origin × 분류기/혼합 3개, 총 18개 확률 예측 완전 일치 |
| 온도 교정 | 목표가 origin과 같거나 이후인 OOS 확률·실제값을 변경해도 결과 불변. 최대 156개 이전 완료 OOS만 사용 |
| 기록된 훈련 종료 | 모든 `last_train_target < origin_date` |
| 저장 결과 재현 | 두 기계 모델 전체 1,112개 OOS 확률 재계산. 최대 차이 `1.11e-16` |
| 비교 정렬 | origin·target·현재 상태·실제 상태·분할 일치, 중복 없음 |
| 원본 보존 | 입력 3개·기준 OOS·후보 OOS·모델 소스의 감사 시작/종료 SHA 일치 |

분류기의 imputer·scaler·회귀/트리 적합은 각 origin의 훈련 구간 안에서 새로 수행한다. 훈련 피처는 origin-2주까지, 훈련 목표는 origin-1주까지이며 현재 테스트 피처를 적합에 넣지 않는다. 기계 모델의 과거 잔차는 origin 직전까지 완료된 관측만 사용하고 현재 변동성은 이미 관측된 입력으로 사용한다.

라벨은 과거 SPY의 추세·변동성·낙폭으로 계산된다. 이 모델의 개선 이유는 그 정의를 바꾸거나 미래 라벨을 넣었기 때문이 아니라, 다음 주에 이동창에서 빠지는 **이미 알려진 과거 값**과 아직 모르는 다음 주 수익률을 구분해 모델링했기 때문이다. 따라서 개선된 점수는 이 프로젝트의 시장 국면 예측에 대한 증거이며, 독립적인 경기침체 예측이나 거래 수익 향상의 증거를 대신하지 않는다.

## 남은 판단

기본 예측으로 잡은 16개 전환은 모두 회복이다. 악화 방향의 포착은 **0/19**로 남아 있다. 실제 활용에서는 회복 탐지 개선과 악화 경보 개선을 분리해 검증해야 한다.

이 연구는 기존 모델의 진단기간 저포착을 확인한 뒤 시작됐다. 새 후보 5개의 결과를 처음 조회하기 전에 코드에서 후보·파라미터를 고정했고, 조회 후 그 값들을 튜닝하지 않았다는 개발 이력은 있지만 별도 사전등록 파일은 없다. 따라서 “한 번도 보지 않은 holdout에서 사전등록 검증을 통과했다”고 표현하지 않는다. 현재 결론은 인과적 시점 제약을 지킨 과거 OOS 재연산에서의 개선이다.

별도 완료-OOS 교정 5종 실험은 선정된 축소 stacking의 국면 Log loss를 0.479355까지 낮췄지만 최근 가중 XGBoost 대비 전환 AP는 낮았고 포착 8/40·오경보 5회는 동일했다. 교정만으로 전환 개선을 입증하지 못했으므로 경계 모델과 같은 성과로 취급하지 않는다.
